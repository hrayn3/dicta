# Agent notes

- To install Dicta for a user, follow [INSTALL.md](INSTALL.md). Steps marked
  **(human)** need the person at the Mac (sudo, permission prompts): ask them.
- Verify transcription headlessly with
  `dist/Dicta.app/Contents/MacOS/Dicta --selftest <audio-file>`
  (make a clip with `say -o clip.aiff "…"`). It needs no permissions.
